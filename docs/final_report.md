# Final Report Structure & Validation Metrics

The validation report output generated by the AI Startup Idea Validator system evaluates startup concepts across 5 dimensions:

## Scoring System
- **Overall Viability Score**: 0 to 100 weighted index.
- **Verdict Categories**:
  - `PROCEED`: Viability Index >= 75
  - `PIVOT`: Viability Index 60 - 74
  - `CAUTION`: Viability Index 45 - 59
  - `STOP`: Viability Index < 45

## Report Sections
1. **Executive Summary & Verdict**
2. **Market Sizing & TAM/SAM/SOM Breakdown**
3. **Competitive Matrix & Moat Evaluation**
4. **SWOT Grid & Risk Score Analysis**
5. **MVP Feature Scope & 4-Week Development Roadmap**
6. **Go-To-Market & Customer Acquisition Strategy**
7. **Actionable Next Steps for Founders**
